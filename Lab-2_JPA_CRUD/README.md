\# Lab 2: JPA CRUD Operations



\## Description

A Java application demonstrating CRUD operations using Jakarta Persistence (JPA), Hibernate, and MySQL.



\## Technologies

\- Java

\- Maven

\- Jakarta Persistence (JPA)

\- Hibernate ORM

\- MySQL



\## CRUD Operations

\- Create: Save a student to the database.

\- Read: Retrieve a student by ID.

\- Update: Modify a student's technology.

\- Delete: Remove a student and verify deletion.



\## Setup

1\. Install and start MySQL.

2\. Create a database named `jpadb1`.

3\. Configure your local MySQL username and password in `src/main/resources/META-INF/persistence.xml`.

4\. Run `com.craft.App` from your IDE.
